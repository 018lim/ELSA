# ELSA — ELS Scan & Assess

ELS(주가연계증권)의 조건을 입력하거나 **증권사 상품 안내 화면을 캡처해 올리면**, 몬테카를로 시뮬레이션으로 **공정가치**, **적정 쿠폰**, **회차별 상환 확률**을 계산하는 웹 앱입니다.

**데모:** https://limelsa.streamlit.app/
첫 접속 시 앱이 잠들어 있으면 깨우는 데 수십 초가 걸릴 수 있습니다.

**평가방법론:** [docs/methodology.md](docs/methodology.md) (상품별 페이오프, 평가모형, 수치 기법, 입력변수, 모델 검증 결과, 한계)

## 1분 체험

1. **샘플 이미지로 체험**을 누르거나 실제 ELS 상품정보를 담은 이미지를 업로드합니다. 상품 안내 이미지를 AI가 읽어 아래 폼을 채웁니다(약 10초).
2. 채워진 값과 "(이미지)" 표시, 확인이 필요한 항목 안내를 봅니다.
3. **평가하기**를 누르면 공정가치, 적정 쿠폰, 회차별 상환 확률 차트가 나옵니다.
4. 시장 데이터의 **시세로 추정**·**국고채 3년 불러오기**를 누르면 실제 시세·금리로 다시 계산할 수 있습니다.

이미지를 쓰지 않아도 첫 화면에 예시 상품이 채워져 있어 바로 **평가하기**를 눌러 볼 수 있습니다.

## 주요 기능

- **조건 입력 두 가지**
  - 직접 입력: 기초자산(1~3개), 상환 배리어(`90-90-85-85-80-75`, 리자드 `90(L75)`도 그대로), 쿠폰, 낙인, 최대 손실률
  - 이미지 자동 입력: 간이투자설명서·상품 요약표·증권사 앱 캡처를 읽어 폼에 채움. 근거 원문을 툴팁으로 보여 주고, 확인이 필요한 항목과 찾지 못한 항목을 따로 안내. 폼을 채우기만 하고 평가는 사용자가 확인한 뒤 실행
- **평가 결과**: 공정가치(액면 대비 %)와 표준오차, 회차별 상환 확률, 만기 원금손실 확률, 손실 시 평균 상환율, 기대 보유기간
- **적정 쿠폰**: 공정가치가 목표값(기본 100%)이 되는 연 쿠폰(녹아웃형은 적정 참여율). 상품 안내에 쿠폰이 없어도 계산
- **시장 데이터 자동 채우기**: Yahoo Finance 과거 종가로 실현변동성·상관계수(기간은 개월 단위로 지정), 최근 1년 실제 배당(지수는 추종 ETF), 국고채 3년 금리(한국은행 ECOS, 접속되지 않으면 네이버 금융)
- **민감도 분석**: 상관계수 ±0.1, 변동성 ±5%p, 금리 ±0.5%p를 같은 난수로 비교
- **엔진 검증 탭**: ELS 평가와 같은 경로 생성·할인 코드로 유럽형 콜옵션을 계산해 Black-Scholes 정답과 비교. 95% 신뢰구간 판정, 수렴 그래프, 행사가 × 변동성 15개 조건 일괄 검증, 대조변수의 표준오차 감소 배율 표시. 콜옵션으로 확인할 수 없는 조기상환·낙인 판정, 관측일 처리, 상관계수·워스트 계산은 극단 조건 21개로 점검

## 지원하는 상품 구조

| 유형 | 지원 범위 |
|---|---|
| 자동조기상환형 | 기초자산 1~3개(워스트 퍼포머), 임의 평가 주기, 회차별 배리어(스텝다운·평평한 배리어), 낙인 매일/매월 말일/만기/노낙인, 더미 쿠폰, **월지급식**, **리자드·슈퍼리자드**(회차별 리자드 배리어) |
| 녹아웃형 | 상승형·하락형·양방향, 매일/만기 관찰, 행사가·참여율·녹아웃 시 수익률·최소 수익률 |
| 공통 | **최대 손실률**로 원금 보장 정도를 표현(0% = 원금지급형 ELB, 10% = 원금 90% 보장, 비움 = 제한 없음). 원금 보장을 가정하지 않음 |

4개 이상 기초자산, 녹아웃 즉시 상환은 지원하지 않습니다. 이미지에서 지원하지 않는 구조가 보이면 경고를 띄웁니다.

## 설계 포인트

- **AI는 옮겨 적기만, 해석은 코드가**: 비전 모델은 이미지의 원문 표기(`85-85-80-75 / KI 40`, `2026/10/30 ~ 2029/11/02`, `손실률(최대) 0%`)를 필드별 문자열로 돌려주고, 단위 변환·날짜 계산·배리어 분해·ELB 판별은 테스트된 순수 함수(`normalize.py`)가 합니다. 모델이 계산을 틀릴 여지를 없애고, 표기마다 단위 테스트를 둘 수 있습니다.
- **교체 가능한 추출기**: Gemini와 Claude가 같은 프롬프트·JSON 스키마를 쓰고, 설정값 하나로 바꿉니다. API 오류는 공통 오류 타입으로 바꿔 화면은 한 가지 방식으로 안내합니다.
- **적정 쿠폰을 반복 없이**: 지급액이 쿠폰에 선형이라는 점을 이용해, 한 번의 시뮬레이션에서 쿠폰 무관 현재가치 A와 쿠폰 1단위 현재가치 B를 모아 `적정 쿠폰 = (목표 − A) / B`로 바로 구합니다.
- **메모리를 아끼는 엔진**: 경로 전체를 저장하지 않고 한 달씩 생성해 워스트 퍼포머의 월말·월중 최저·최고만 넘깁니다. 10만 경로 × 3년 일별 시뮬레이션이 노트북에서 약 3초.
- **실제 데이터의 함정 처리**: Yahoo의 배당 요약값은 항목마다 단위가 달라 실제 지급 내역으로 직접 계산하고, 지수 배당은 추종 ETF로, 시세가 비어 있는 `^KS200`은 KODEX 200 ETF로 대체합니다.
- **정답을 아는 문제로 엔진 검증**: 새 시뮬레이터를 만들지 않고 ELS 평가와 같은 경로 생성·할인 코드에 페이오프만 콜옵션으로 바꿔 Black-Scholes와 비교합니다. 콜옵션으로 확인되지 않는 판정 로직은 극단 조건으로 따로 점검하고, 기대값은 엔진 코드를 쓰지 않고 공식으로 계산해 엔진 오류가 기대값에 숨지 않게 했습니다.
- **대조변수에 맞는 표준오차**: 쌍을 이룬 경로는 서로 독립이 아니므로 경로별 표준편차 / √N은 표준오차를 크게 잡습니다(깊은 내가격에서 최대 약 8.6배). 판정은 쌍 평균 기준으로 합니다.
- **외부 서비스 실패를 전제로 설계**: 배포 서버에서 한국은행 ECOS 접속이 실패한 적이 있어 금리는 ECOS → 네이버 금융 → 직접 입력 순서로 조회합니다. 비공식 주소는 응답을 검사해 형식이 바뀌면 값을 넣지 않고, 어떤 외부 오류가 나도 폼과 평가는 그대로 쓸 수 있습니다.
- **테스트**: 기준값 회귀 테스트, 손으로 계산 가능한 결정적 경로로 검증한 월지급식·리자드·녹아웃 테스트, 실제 증권사 캡처 8장의 판독 테스트(로컬 전용), Streamlit AppTest로 만든 화면 흐름 테스트 등 .

## 평가 모형

- 위험중립 기하브라운운동, 촐레스키 분해로 기초자산 간 상관관계 반영
- 연 252영업일 일별 시뮬레이션, 대조변수 분산 축소, 같은 시드로 재현
- 변동성·배당·금리는 상수. 변동성은 과거(실현) 변동성 또는 참고용 기본값

실제 평가사는 내재변동성 곡면, 금리 기간구조, 이산배당, 발행사 신용위험 등을 추가로 반영합니다. 이 프로젝트는 상품 구조와 평가 방법을 이해하기 위한 학습용 평가기입니다. 수식과 가정, 검증 결과는 [평가방법론 문서](docs/methodology.md)에 정리했습니다.

## 예시 결과

삼성전자 / SK하이닉스, 3년 만기 6개월 단위, 90-90-85-85-80-75, KI 50(매일), 연 8%, 더미 쿠폰
(변동성 32% / 45%, 배당 2.0% / 0.8%, 상관계수 0.6, 금리 2.8%, 10만 경로)

| 항목 | 값 |
|---|---|
| 공정가치 | 약 85.6% |
| 6개월 조기상환 확률 | 약 47% |
| 만기 원금손실 확률 | 약 27% |
| 적정 연 쿠폰 (공정가치 100% 기준) | 약 30% |

공정가치가 일반적인 발행 수준(94~99%)보다 낮습니다. 이 변동성 가정에서는 연 8% 쿠폰이 위험에 비해 부족한 조건이라는 뜻입니다.

## 엔진 검증

앱의 **엔진 검증** 탭에서 직접 실행할 수 있습니다. 값은 기본 설정(시드 42) 기준입니다.

| 검증 | 조건 | 결과 |
|---|---|---|
| 정답 비교 | S0=K=100, σ=20%, r=3%, T=1년, 50만 경로 | MC 9.4121, Black-Scholes 9.4134 (95% 신뢰구간 안) |
| 일괄 검증 | 행사가 80~120% × 변동성 10·20·30% | 15개 조건 모두 통과 |
| 대조변수 효과 | 10만 경로 | 표준오차 0.0445 → 0.0332 (1.34배 감소) |
| ELS 로직 점검 | 낙인 제거, 변동성 0, 1회차 상환, 상관계수 1, 변동성·상관계수 방향, 관측 빈도 | 21개 테스트 모두 통과 |

ELS 로직 점검은 극단 조건에서 상식대로 작동하는지 확인하는 것으로, 모든 조건의 정확성을 증명하지는 않습니다. 95% 신뢰구간으로 판정하는 ※ 항목은 시드에 따라 가끔 ⚠️가 나올 수 있습니다.

## 기술 스택

- Python 3.11, Streamlit, numpy, pandas, Pydantic, altair
- 이미지 분석: Google Gemini API(기본, `gemini-flash-lite-latest` 권장) / Anthropic Claude API(선택)
- 시장 데이터: yfinance, 한국은행 ECOS API, 네이버 금융(금리 대체 조회)
- 배포: Streamlit Community Cloud

## 로컬 실행

```powershell
git clone https://github.com/018lim/elsa.git
cd elsa
py -3.11 -m venv .venv
.\.venv\Scripts\Activate.ps1
pip install -r requirements-dev.txt

copy .streamlit\secrets.toml.example .streamlit\secrets.toml
# secrets.toml에 GEMINI_API_KEY(및 선택적으로 ECOS_API_KEY) 입력

streamlit run app.py
```

브라우저에서 http://localhost:8501 을 엽니다. API 키가 없어도 직접 입력과 평가는 그대로 쓸 수 있고, 이미지 자동 입력만 비활성화되고, 금리는 네이버 금융 값으로 불러옵니다.

### 설정값

| 이름 | 설명 |
|---|---|
| `EXTRACTOR` | `gemini` 또는 `claude` |
| `EXTRACTOR_MODEL` | 사용할 모델 이름 (권장: `gemini-flash-lite-latest`) |
| `GEMINI_API_KEY` | Google AI Studio에서 발급 |
| `ANTHROPIC_API_KEY` | `EXTRACTOR=claude`일 때만 필요 |
| `ECOS_API_KEY` | 한국은행 ECOS 인증키 ("국고채 3년 불러오기"에 사용, 비우면 네이버 금융 값 사용) |
| `ACCESS_CODE` | 설정하면 이미지 자동 입력 전에 접근 코드를 묻습니다 (비우면 없음) |
| `MAX_EXTRACTIONS_PER_SESSION` | 접속 한 번당 자동 입력 횟수 제한 (기본 5) |

API 키는 `.streamlit/secrets.toml`(로컬) 또는 Streamlit Cloud의 Secrets 설정에만 넣고 저장소에 커밋하지 마세요. Claude를 쓸 경우 Anthropic 콘솔에서 이 프로젝트 전용 키에 월 사용 한도를 걸어 두는 것을 권장합니다.

### 종목 추가

`elsa/data/underlyings.json`에 항목을 추가하면 코드 수정 없이 종목명 인식, 티커, 기본 변동성·배당이 적용됩니다. 지수처럼 Yahoo에 배당 정보가 없으면 `div_ticker`에 추종 ETF를 적습니다.

```json
"현대차": {"ticker": "005380.KS", "vol": 0.30, "div": 0.03, "aliases": ["현대자동차"]}
```

## 개인정보와 면책

- 업로드한 이미지는 저장하지 않지만 외부 AI 서비스로 전송됩니다. Gemini 무료 티어로 보낸 내용은 Google의 서비스 개선에 쓰일 수 있으니, 계좌번호 등 개인정보가 담긴 화면은 올리지 마세요.
- 이 평가기의 결과는 투자 권유나 공식 평가가격이 아닙니다. 모형 가정과 입력값에 따라 결과가 크게 달라질 수 있습니다.
